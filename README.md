## ⚙️ Computer Intelligence

### 🎒 Genetic Algorithm for the Knapsack Problem

A MATLAB genetic algorithm for the 0–1 Knapsack Problem with 100 items and a capacity constraint. The implementation includes performance-oriented changes, such as reducing repeated calculations.

**Topics:** Genetic algorithms · Optimization · MATLAB  
📁 **[View project](Computer_Intelligence/Project1_Genetic_Algorithms/)**

### 🧠 Function Approximation with Neural Networks

A MATLAB multilayer perceptron (MLP) trained to approximate a nonlinear function of two variables, with experiments involving network architecture, gradient-descent training, and early stopping.

**Topics:** MLP · Function approximation · MATLAB  
📁 **[View project](Computer_Intelligence/Project_2_Neural_Networks/)**

### 🚗 Fuzzy Cruise Control

Design and simulation of a Mamdani fuzzy inference system for vehicle cruise-speed control using membership functions and fuzzy rules.

**Topics:** Fuzzy logic · Control systems · MATLAB  
📁 **[View project](Computer_Intelligence/Project_3_Fuzzy_Logic/)**

## 🧠 Pattern Recognition

### 📩 Bayesian Classification & Decision Theory

Python/Jupyter exercises covering Bayesian spam classification, decision regions, Bayes risk, Gaussian classifiers, error bounds, and Bayesian parameter estimation.

**Topics:** Bayesian inference · Decision theory · Python  
📁 **[View project](Pattern_Recognition/Project_1_Bayesian_Theory/)**

### 📈 Non-Parametric Estimation, SVM & Dimensionality Reduction

Exercises using Parzen-window density estimation, linear and RBF SVMs, and PCA/LDA for classification and feature-space analysis, including cross-validation and confusion matrices.

**Topics:** Density estimation · SVM · PCA · LDA  
📁 **[View project](Pattern_Recognition/Project_2_Advanced_Classification/)**

### 🔎 Clustering & Multidimensional Scaling

Unsupervised-learning exercises using K-Means and hierarchical clustering, cluster evaluation measures, PCA, and classical multidimensional scaling (MDS).

**Topics:** Clustering · PCA · MDS · Model evaluation  
📁 **[View project](Pattern_Recognition/Project_3_Clustering_MDS/)**

### 🧪 Final Project — Computer Vision & Molecular Binding Classification

A two-part project involving image classification and molecular data classification.

**Part 1 — Face Mask Detection**
- Developed and evaluated custom convolutional neural networks (CNNs).
- Explored transfer learning with ResNet-18.
- Investigated classification behavior across different mask-wearing cases.

**Part 2 — Molecular Binding Classification**
- Investigated binary classification of molecular binding outcomes.
- Applied dimensionality-reduction techniques, including PCA.
- Experimented with MLPs, SVMs, and ensemble approaches.

**Topics:** `Computer Vision` `CNN` `ResNet-18` `Transfer Learning` `PCA` `MLP` `SVM`  
📁 **[View project and project-specific README](Pattern_Recognition/Final_Project/)**
