# Σύστημα Ασαφούς Ελέγχου Ταχύτητας (Fuzzy Cruise Control System)

Αυτό το repository περιλαμβάνει τη σχεδίαση και υλοποίηση ενός **Συστήματος Ασαφούς Λογικής (Fuzzy Logic System)** σε περιβάλλον **MATLAB** για τον αυτόματο έλεγχο και τη σταθεροποίηση της ταχύτητας ενός αυτοκινήτου (Cruise Control). Η εργασία αναπτύχθηκε στο πλαίσιο της 3ης εργασίας του μαθήματος **Υπολογιστική Νοημοσύνη** του Τμήματος Ηλεκτρολόγων Μηχανικών και Μηχανικών Υπολογιστών (ΔΠΘ).

## 📝 Περιγραφή Προβλήματος
Στόχος του συστήματος είναι να διατηρεί την ταχύτητα ενός οχήματος σταθερή στα **120 km/h**, λαμβάνοντας υπόψη την τρέχουσα κατάσταση του οχήματος και εφαρμόζοντας την κατάλληλη δύναμη στα μηχανικά μέρη (γκάζι ή φρένο) για την ομαλή προσαρμογή της πορείας του.

## 🛠️ Δομή & Παραμετροποίηση του Συστήματος
Το σύστημα υλοποιήθηκε με τη χρήση του **Fuzzy Logic Designer** της MATLAB και βασίζεται στις εξής μεταβλητές:

### 1. Μεταβλητές Εισόδου (Inputs)
* **Ταχύτητα (Speed):** Ορίστηκε στο διάστημα [0, 240] km/h. Χωρίστηκε σε 3 ασαφή σύνολα (υποδιαστήματα):
  * *Αργό (Slow)* -> Συνάρτηση συμμετοχής: `gauss2mf`
  * *Μεσαίο (Medium)* -> Συνάρτηση συμμετοχής: `gaussmf` (κεντραρισμένη γύρω από τον στόχο των 120 km/h)
  * *Γρήγορο (Fast)* -> Συνάρτηση συμμετοχής: `gauss2mf`
* **Επιτάχυνση (Acceleration):** Ορίστηκε στο διάστημα [-10, 10] $m/s^2$. Χωρίστηκε σε 3 ασαφή σύνολα:
  * *Αρνητική (Negative)* -> Συνάρτηση συμμετοχής: `gauss2mf`
  * *Μηδενική (Zero)* -> 🔬 *Σημείωση:* Χρησιμοποιήθηκε η στενή συνάρτηση `trimf` (τριγωνική) αντί για Gaussian, καθώς προσφέρει μεγαλύτερη ακρίβεια και άμεση απόκριση όταν η επιτάχυνση μηδενίζεται.
  * *Θετική (Positive)* -> Συνάρτηση συμμετοχής: `gauss2mf`

### 2. Μεταβλητή Εξόδου (Output)
* **Δύναμη Μηχανικών Μερών (Break_Accelerator):** Καθορίζει τη δράση του συστήματος στο διάστημα [-0.853, 0.853] (ώστε οι τελικές έξοδοι μετά την αποασαφοποίηση να κυμαίνονται ομαλά μεταξύ -0.5 και 0.5). Χωρίστηκε σε 3 υποδιαστήματα:
  * *Φρένο (Break)* -> Συνάρτηση συμμετοχής: `gauss2mf`
  * *Τίποτα (Nothing)* -> Συνάρτηση συμμετοχής: `gaussmf`
  * *Γκάζι (Accelerate)* -> Συνάρτηση συμμετοχής: `gauss2mf`

## 📜 Κανόνες Ασαφούς Συμπερασμού (Fuzzy Rules)
Η συμπεριφορά του Cruise Control καθορίζεται από έναν συμπαγή και αποτελεσματικό πίνακα κανόνων:
1. **Αν** η ταχύτητα είναι *Αργή*, **τότε** πάτα *Γκάζι*.
2. **Αν** η ταχύτητα είναι *Γρήγορη*, **τότε** πάτα *Φρένο*.
3. **Αν** η ταχύτητα είναι *Μεσαία* **και** η επιτάχυνση είναι *Θετική*, **τότε** πάτα *Φρένο* (για την αποφυγή υπέρβασης του ορίου).
4. **Αν** η ταχύτητα είναι *Μεσαία* **και** η επιτάχυνση είναι *Αρνητική*, **τότε** πάτα *Γκάζι* (για τη διατήρηση της ταχύτητας).
5. **Αν** η ταχύτητα είναι *Μεσαία* **και** η επιτάχυνση είναι *Μηδενική*, **τότε** *Μην κάνεις τίποτα* (ιδανική κατάσταση σταθερότητας).
